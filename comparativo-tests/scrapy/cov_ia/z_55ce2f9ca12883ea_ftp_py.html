1""" 

2An asynchronous FTP file download handler for scrapy which somehow emulates an http response. 

3 

4FTP connection parameters are passed using the request meta field: 

5- ftp_user (optional, falls back to FTP_USER) 

6- ftp_password (optional, falls back to FTP_PASSWORD) 

7- ftp_passive (optional, falls back to FTP_PASSIVE_MODE) sets FTP connection passive mode 

8- ftp_local_filename 

9 - If not given, file data will come in the response.body, as a normal scrapy Response, 

10 which will imply that the entire file will be on memory. 

11 - if given, file data will be saved in a local file with the given name 

12 This helps when downloading very big files to avoid memory issues. In addition, for 

13 convenience the local file name will also be given in the response body. 

14 

15The status of the built html response will be, by default 

16- 200 in case of success 

17- 404 in case specified file was not found in the server (ftp code 550) 

18 

19or raise corresponding ftp exception otherwise 

20 

21The matching from server ftp command return codes to html response codes is defined in the 

22CODE_MAPPING attribute of the handler class. The key 'default' is used for any code 

23that is not explicitly present among the map keys. You may need to overwrite this 

24mapping if want a different behaviour than default. 

25 

26In case of status 200 request, response.headers will come with two keys: 

27 'Local Filename' - with the value of the local filename if given 

28 'Size' - with size of the downloaded data
